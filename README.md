## ⚡ Highlights & Architecture

- **Editorial Brutalist Aesthetic:** High-contrast palette (`#F3F2EC`, `#121212`, `#D4F82C` lime) with custom typography pairing (*Syne* display headings, *Instrument Serif* italic accents, and *Plus Jakarta Sans* body).
- **Interactive Cursor Physics:** Real-time tech stack icon trail following cursor movement with smooth spring physics and automatic decay.
- **Deep Technical Case Studies:** Detailed modal views breaking down **Challenge $\rightarrow$ Architecture $\rightarrow$ Metrics $\rightarrow$ Stack**.
- **100% Performance-Optimized:** Built with React 19 and Vite 8, achieving sub-second loads and smooth 60 FPS interactions.

## 🚀 Running Locally

### Prerequisites
- Node.js (v18 or higher recommended)
- npm / pnpm / yarn

### Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/nobody294469/Portfolio.git
   cd Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

4. **Build for production:**
   ```bash
   npm run build
   ```
